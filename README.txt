AGENT FORGE — multi-AI app builder
===================================
FILES: index.html (the app), manifest.webmanifest, sw.js, icon-192.png, icon-512.png

RUN NOW (no install): open index.html in your phone's Chrome.
- Tap "Demo" to see a multi-page preview instantly.
- Default agents = built-in Claude (free, no key). Add other AI keys in the Keys tab.

FEATURES
- 8 agents: Researcher, Planner, UI/UX, Frontend, Backend, QA, Optimizer, Reviewer.
- Multi-page output (one self-contained index.html with working page nav).
- Attach files/images to guide the agents (Build tab).
- Save / Load projects on this device (Build tab).

INSTALL AS ANDROID APP
1. On a computer go to app.netlify.com/drop, drag this folder in -> get an https link.
2. Open the link on Android Chrome -> menu -> "Install app".

REAL .APK (no tools)
1. Host the folder (step above) for an https link.
2. Go to pwabuilder.com, paste the link -> Package For Stores -> Android -> Download.
